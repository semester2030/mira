📱 أيقونة تطبيق ميرا — توليد تلقائي

المصدر: assets/images/mira_logo_full.png (الشعار الكامل داخل التطبيق)

لإعادة بناء أيقونات iOS و Android بدقة:

  python3 scripts/build_app_icons.py
  dart run flutter_launcher_icons
  flutter clean && flutter run

النتيجة:
  - assets/images/app_icon.png (1024 — شعار دائري فقط بدون نص)
  - assets/images/app_icon_foreground.png (Android adaptive)
  - ios/Runner/Assets.xcassets/AppIcon.appiconset/*
  - android/app/src/main/res/mipmap-* / drawable-*

ملاحظة: لا تضعي نص «MIRA» في app_icon.png — النص لا يظهر على الشاشة الرئيسية.
