١. الحكم التنفيذي

✅ الرؤية صحيحة — والهيكل الحالي يتحملها

ميرا اليوم = Perfect Corp wrapper + radar chart + marketplace tags. الرؤية الجديدة = Mira Intelligence Layer بين YouCam والمستخدم. لا حاجة لإعادة بناء المشروع — بل إضافة module جديد وربط ما هو موجود.

⭐⭐⭐⭐⭐ قيمة تجارية
⭐⭐⭐⭐ ملاءمة الهيكل
⭐⭐ جاهزية فورية
~30% نسبة تنفيذ الرؤية اليوم

التدفق المستهدف (Core Architecture)

User Photo ↓ Perfect Corp Analysis ← محرك فقط (موجود) ↓ Mira Intelligence Layer ← جديد — لا يُرى للمستخدم ↓ Personalized Report ← لغة بشرية، لا أرقام خام ↓ Treatment Plan ← صباح / مساء مخصص ↓ Product Recommendations ← marketplace + rules ↓ Progress Tracking ← trends من التاريخ

⚠️ قاعدة ذهبية

المستخدم لا يرى أبداً: Oiliness: 73 · Pores: 65 · Wrinkles: 28

يرى بدلاً: «نلاحظ زيادة بسيطة في إفراز الدهون في منطقة T-Zone» — مولّدة من narrative-engine.

المرحلة 5 — Face Health Map (مشروطة — لا heuristic markers)

أكبر خطر في الخطة Gate إلزامي قبل أي كود UI 22–32 ملف إذا spatial = نعم · 8–12 إذا spatial = لا

لماذا خامسة؟ YouCam الحالي يُرجع scores عامة فقط — لا coordinates. رسم markers «دقيقة» بدون بيانات مكانية = كسر ثقة المستخدم.

📜 Product Policy (ملزمة)

  1. Face Map = مشروطة بتوفر بيانات مكانية حقيقية من Perfect Corp (mask · regional scores · coordinates).
  2. ممنوع عرض علامات/نقاط حمراء «دقيقة» على الوجه إذا التحليل global-only.
  3. Heuristic (T-zone = oiliness) — narrative نصي فقط + disclaimer — ليس face map.
  4. كل response يحمل spatialConfidence: "none" | "regional" | "pixel" — UI يقرأها ولا يتجاوزها.

✅ ما نُفّذ — المرحلة 5 (يونيو 2026)

نُفّذت بمبدأ Validation-First: تحقق تقني من Perfect Corp قبل أي UI مكانية. النتيجة: YouCam يعطي scores عامة فقط — فاختارنا Educational Face Map (استرشادي · بصري · صادق) — وليس Medical Face Map (markers حمراء · تشخيص موضعي وهمي).

🎨 Educational Face Map — ما تراه المستخدمة

  1. وجه أنثوي فاخر — الجبهة · تحت العين · الخدين · الأنف · الذقن · خط الفك.
  2. تظليل بنفسجي خفيف على مناطق شائعة (مثل T-Zone) — بدون نقاط حمراء.
  3. بطاقة insight: «بناءً على نتيجة المسام المرتفعة، غالباً ما تظهر في T-Zone — منطقة شائعة وليست تشخيصاً مؤكداً على وجهك.»
  4. Disclaimer ثابت: «الخريطة التالية استرشادية وليست تشخيصاً مكانياً دقيقة.»
  5. شارة الثقة: ثقة منخفضة — استرشادي (حتى ترقية YouCam).

الفرق الجوهري: Medical Map = «المشكلة هنا» · Educational Map = «غالباً في هذه المنطقة الشائعة».

لماذا لم نرسم markers حمراء؟

Contract — FaceHealthMapPayload (Phase 5)

interface FaceHealthMapPayload {
  enabled: boolean;
  confidence: 'low' | 'medium' | 'high';
  confidenceLabelAr: string;       // ثقة منخفضة — استرشادي
  mode: 'educational' | 'regional' | 'spatial';
  titleAr: string;
  disclaimerAr: string;
  zones: Array<{
    id: 'forehead' | 'under_eye' | 'cheek_left' | 'cheek_right' | 'nose' | 'chin' | 'jawline' | 't_zone';
    labelAr: string;
    highlight: boolean;
    highlightColor: string;        // #C19EE0 educational purple
    source: 'educational' | 'perfect_corp';
  }>;
  insightCards: Array<{ concernLabelAr; zoneLabelAr; bodyAr }>;
}
