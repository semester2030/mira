Feature Freeze — إلزامي

قواعد التجميد

  • لا ميزات UI جديدة
  • لا محركات ذكاء إضافية
  • لا توسيع catalog إلا استبدال PNGs بنفس الأسماء
  • مسموح: إصلاح bugs · حذف كود ميت · اختبارات · قياس · توثيق
  • مسموح بعد الأسبوع 4: استبدال Vision · تفعيل IAP · FASHN على Render
