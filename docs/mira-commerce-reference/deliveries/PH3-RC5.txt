2. محوّل S3-compatible مرشح للرفع والقراءة والحذف. الاختيار غير معتمد. Perfect Corp ليس هذا المخزن.
3. المسودة تبقى غير عامة، والشريك الآخر لا يقرأها، والسحب يحجب المسار العام، وفشل حفظ الصف ينظّف الملف الجديد أو يسجل التنظيف. لا بيانات اعتماد في الواجهات.
4. الاختبارات مفصولة: عزل، محاكي محلي، HTTP مع PostgreSQL. لا تحقق على مورد سحابي.
