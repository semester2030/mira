ما نُفذ
1. قرار الإدارة مربوط بالنسخة داخل معاملة مع قفل صف وتحديث مشروط. النسخة القديمة 409. فشل المعاملة يبقي المنشور. تنظيف التخزين بعد الالتزام.
2. زر الاعتماد يرسل رقم النسخة التي اكتمل عرضها ولا يجلب نسخة أحدث داخل الضغط نفسه.
3. فيديو MP4 قابل للفك وصورة اختبار، وحدود 5MB و20MB، وتمييز فشل القراءة عن غياب الملف.
4. الاستيراد التجريبي مرفوض في الإنتاج، والسجلات simulated تبقى خارج كل المسارات العامة بعد الاعتماد.
5. تعديل منتج وخدمة قائمين على المعرف نفسه، مع بقاء المنشور عند الرفض.
6. الأدلة داخل الموقع.

- HTTP وقاعدة بيانات محلية: scripts/run-marketplace-rc6-integration.sh ويشمل marketplace وcatalog-content وcatalog-storage وcatalog-content.rc3. السجل: evidence/ph3-rc3/rc3-integration.log. خرج 0 ونظف القاعدة.
- التخزين المحلي: عملية ثانية قرأت الملف. الإنتاج لم يُختبر.
- المتصفح: Chrome 153 headless بنافذة 1280 و480، بلا تصغير DOM. السجل: evidence/ph3-rc3/ui-assertions.txt.
- مدقق Firebase في اختبارات HTTP بديل اختبار ولا يثبت اتصال Firebase الحي.
