# المجوهرات — جدول الإغلاق

- **نسخة العمل المحلي:** `mira/elegance-e1-taxonomy-foundation` فوق `b27557c` + تغييرات مجوهرات غير مُودَعة/غير منشورة.
- **اختبار محلي منفَّذ:** `npx tsx mira-api/src/marketplace/taxonomy/jewelry-reorg.schema-tests.ts` → **ok**.
- **إنتاج Render** (`https://mira-api-n4p3.onrender.com`): jewelry `definitionsVersion` ما زال القديم (بدون pendants/sets/caps) — **الرحلات الحية غير منفَّذة**.
- **حكم الإغلاق:** **غير مغلق**. لا صور محرر/تطبيق من النسخة النهائية المنشورة. النجاح المحلي ≠ الإنتاج.

## ما أُنجز محليًا
- taxonomy jewelry v2: فروع قطع + معادن/أحجار/صفات browse + jewelry.cap.* للمنح
- سياسة مواد من الخادم (رفض ستيل/نحاس؛ فضة مطلية ≠ ذهب؛ ألماس مختبري بعلم إدارة)
- حقول المحرر الأفقي حسب الفرع + عبارات وصف
- فلاتر كتالوج: مركز قيراط مستقل، sellUnit، stoneTypes، اكتشاف، استبعاد مطلي من ذهب
- لقطة مواصفات الطلب `spec_snapshot_json`
