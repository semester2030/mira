# 03 — مصفوفة الوسائط

## 1. مقارنة المحررات

| الطبقة | محرر المنتج | محرر الخدمة | محرر إعلان المشهور |
|---|---|---|---|
| الواجهة | `partners-portal/web/js/catalog-journey.js` — موضع `main` + `detail` | نفس الملف لنماذج الخدمات | `ads.js` — **نص + هدف فقط، بلا رفع ملفات** |
| API رفع | `POST /partners-portal/products\|services/:id/media` | نفسها | **لا مسار** |
| التخزين | `CatalogMedia` (`ownerKind` = product/service) + S3 | نفسها | لا صفوف `ownerKind=ad` |
| عرض Discover للإعلان | — | — | `publishedMedia(targetKind, targetId)` ← وسائط **الهدف** |

الخلاصة: إعلان المشهور اليوم **يعيد استخدام وسائط التاجر/المركز**، وهذا يناقض مطلب «وسائط الإعلان مستقلة عن وسائط المتجر».

## 2. مسار الملف (منتج/خدمة — القابل لإعادة الاستخدام)

1. اختيار ملف في البوابة (`addStaged`) مع تحقق نوع/حجم/مدة في الواجهة  
2. رفع Base64/ثنائي إلى API → sniff MIME → حد بايتات → `storage.put`  
3. صف `CatalogMedia` بحالة `publication=draft` غالبًا حتى الاعتماد  
4. إعادة ترتيب / تعيين أساسي / إزالة معلّقة  
5. عند النشر: وسائط `published` تظهر عبر `/api/v1/marketplace/media/:id`  
6. التطبيق يستهلك الروابط في Discover والتفاصيل  

**نجاح الرفع ≠ جاهزية للمشاهدة العامة** قبل اعتماد المحتوى وظهور الـ URL القابل للقراءة.

## 3. الحدود الفعلية بالأدلة

| القيد | الواجهة (بوابة) | الخادم | التخزين/الحافة |
|---|---|---|---|
| صيغ صور | JPEG/PNG/WebP + HEIC→JPEG | `IMAGE_MIME` jpeg/png/webp | يعتمد على S3 |
| صيغ فيديو | MP4/MOV/M4V | `VIDEO_MIME` + `mp4Playable` (وجود `moov`) | — |
| حجم صورة | 5MB (واجهة) | `IMAGE_MAX_BYTES = 5MB` | — |
| حجم فيديو | 70MB | `VIDEO_MAX_BYTES = 70MB`؛ مدة ≤ 300ث | JSON body عبر Cloudflare ~100MB |
| مدة فيديو | 5 دقائق metadata | `VIDEO_MAX_DURATION_SECONDS = 300` | — |
| عدد فيديوهات العرض الرئيسي | `videos.multiple = false` → **ملف واحد لكل اختيار**؛ النص: «فيديو واحد أو مجموعة صور» | **لا حد عددي صريح** على `count` | — |
| عدد الصور | `images` متعددة بلا سقف واجهي واضح | لا سقف عددي صريح؛ يشترط ≥1 صورة عند الإرسال (إلا استثناء مطوّر) | — |
| تفاصيل | صور+فيديو بدون `multiple=false` على الفيديو | نفس الجدول | — |
| ترتيب/غلاف | إعادة ترتيب حسب الموضع؛ غلاف صورة غير detail | `reorder`، `isPrimary` | — |

مراجع: `catalog-content.policy.ts` L1–6؛ `catalog-journey.js` L718–729، L1566+؛ `catalog-content.service.ts` L90–91، L133، L670.

## 4. حكم مستقل على الحالتين المطلوبتين

### أ) ٣ مقاطع فيديو في إعلان واحد

| طبقة | الحكم |
|---|---|
| محرر إعلان | **غير مدعوم** (لا محرر) |
| محرر منتج رئيسي | **غير مدعوم عمليًا** — واجهة العرض الرئيسي تقصر على فيديو واحد |
| محرر تفاصيل منتج | ممكن تجميعيًا إن رُفعت عدة فيديوهات detail، لكنها ليست شريحة Discover الرئيسية |
| خادم | يقبل عدة صفوف فيديو بلا سقف عددي موثّق |
| إعلان منشور | يعرض وسائط الهدف؛ لا هوية وسائط للإعلان |

**النتيجة:** حالة «٣ فيديوهات لإعلان مشهور» **غير متحققة** في المنتج الحالي.

### ب) فيديو واحد + ١٠ صور

| طبقة | الحكم |
|---|---|
| محرر إعلان | غير مدعوم |
| محرر منتج رئيسي | فيديو واحد + صور متعددة بلا سقف ١٠ في الواجهة/الخادم — **ممكن تقنيًا على المنتج** لا على الإعلان |
| إعلان | سيُظهر مزيج وسائط **المنتج** لا تجربة المشهورة |

**النتيجة:** مدعومة جزئيًا كوسائط كتالوج منتج؛ **غائبة** كوسائط إعلان مستقلة.

## 5. سيناريوهات تشغيل حساسة

| سيناريو | السلوك الحالي (منتج/خدمة) | للإعلان |
|---|---|---|
| إعادة ترتيب بعد النشر | مسودة ترتيب/`draft*` حتى اعتماد لاحق | لا ينطبق |
| فشل الملف العاشر وإعادة المحاولة | أخطاء تُحفظ على العنصر المرحلي؛ الرفع الذري يفشل وينظف المفتاح | لا مسار |
| منع النشر قبل الجاهزية | يتطلب صورة واحدة على الأقل (قاعدة إرسال) | نشر إعلان لا يتحقق من وسائط إعلان |
| حذف وسيط إعلان vs أصل التاجر | — | أي حذف يمس أصل التاجر إن شُورك — **خطر تصميمي** |

## 6. سياسة وسائط مشتركة مقترحة (قابلة للتهيئة)

مرجع إعداد واحد (مثال أسماء):

```
mediaPolicy.ad = {
  maxVideos: 3,
  maxImages: 10,
  maxTotal: 12,
  allowVideoOnly: true,          // استثناء معلن لحالة ٣ فيديوهات
  requireImageIfNoVideo: false,  // يختلف عن سياسة المنتج الحالية
  imageMaxBytes, videoMaxBytes, videoMaxSeconds // وراثة من catalog-content.policy
}
mediaPolicy.productMain = { maxVideos: 1, maxImages: N, ... } // الإبقاء على سلوك Discover الحالي ما لم يُقرر خلاف ذلك
```

**استثناءات معلنة فقط:**  
1) إعلان قد يكون فيديوهات فقط (عكس «صورة واحدة على الأقل» للمنتج).  
2) سقف الإعلان أعلى من فيديو Discover الرئيسي الواحد.

**مكونات إعادة الاستخدام:** `CatalogMedia` + `catalog-content.service` (رفع/ترتيب/أساسي/قراءة) + `catalog-media.storage`/`s3` + مشغّل Discover + تحقق المدة `catalog-video-duration` — مع **`ownerKind: 'ad'`** ومسارات `/partners-portal/ads/:id/media` جديدة، ومنع حذف أصل التاجر من محرر الإعلان.
