# خطوات فايز — تكرار رحلة المشاهير v1

## بيئة

1. من `mira-wt-creator-ads` شغّل API المحلي مع هجرة `creator_profiles` وقاعدة اختبار.
2. افتح `partners-portal/web/dashboard.html` متصلة بنفس API، بحساب **المطوّر**.
3. شغّل تطبيق Flutter على محاكي/جهاز يشير لنفس الـ API.

## الرحلة

1. من القائمة الجانبية: **حساب المشهور** → تسجيل كمشهور (اسم + صورة + نبذة) → حفظ.
2. اخرج وادخل مجددًا → تأكد أن الملف واحد وأن **منتجاتي/خدماتي/إعلاناتي** ما زالت ظاهرة.
3. **إعلاناتي** → إضافة إعلان منتج → اربط منتجًا → ارفع **٣ فيديوهات** → نشر (المطوّر ينشر مباشرة).
4. إضافة إعلان خدمة → ارفع **فيديو + ١٠ صور** → نشر.
5. في التطبيق: الرئيسية → دائرة **المشاهير** فوق «اكتشفي عالم ميرا» → الدليل يعرض صورتك حتى قبل إعلان إن كان الملف عامًا.
6. افتح صفحتك → شغّل الإعلانين وتحقق من ترتيب الوسائط، وأن **التفاصيل** تفتح العرض الأصلي، وأن وسائط التاجر لم تُحذف بعد حذف وسيط من الإعلان.

## ما لا يُتوقَّع في v1

- إسناد بيع/حجز لـ `adId` — فقط `link_open`.
