  • Phase 0 قبل كل شيء — المستودع لديه فجوة مصداقية مثبتة (mock + تسمية جمال).

  • Phase 7 تحقق/تحيز قبل الإطلاق — يمنع ادعاءات App Store غير مدعومة.
  • حوكمة مرحلة بمرحلة — تناسب فريقًا صغيرًا ومستودعًا كبيرًا (Flutter + Nest + docs).

ما يحتاج معايرة (لا رفض)

  • Phase 1 واسعة — نفّذ ports للمسارات الحرجة فقط (Skin/Fashion/TryOn) أولًا، لا 12 منفذًا دفعة واحدة.
  • Phase 4/5 قد تتوازي جزئيًا بعد Phase 3 إذا التقطت الجودة (Phase 2) جاهزة — لكن ليس قبل Phase 0–1.
  • Phase 6 تعتمد على Vision الموجود — ركّز على عزل legacy لا إعادة بناء كاملة.
  • نصوص الموقع التسويقي (docs/index.html) جزء من مشكلة المصداقية ويجب إدراجها في 0.4.
