⚖️ نطاق التنفيذ — ما يُنفَّذ وما لا يُنفَّذ

✓ يُنفَّذ (Phase A — الآن)

  • تغيير لون قطعة واحدة على صورة المستخدم
  • اختيار القطعة (فستان · بلوزة · عباءة · …)
  • برومبت عربي قابل للتعديل قبل الإرسال
  • مقارنة قبل/بعد · سحب للمقارنة
  • حفظ الوجه · الخلفية · الإكسسوارات (عبر البرومпт)

✕ لا يُنفَّذ (حتى لو كُتب في البرومبت)

  • إضافة حقيبة · عقد · حذاء جديد
  • تغيير مكياج أو تسريحة على الصورة
  • استبدال الإطلالة كاملة بقطعة متجر
  • تنفيذ «كل اقتراحات ميرا» دفعة واحدة
  • برومпт حر بدون حدود → غير مضمون

    🛡️ PHASE Q — QUALITY ENFORCEMENT LAYER (QEL)

    AI Garment Integrity System — سلامة الحقيقة البصرية

    المشكلة ليست «هل نستطيع بناء Atelier؟» — بل: هل النتيجة تجعل المستخدمة تقول: هذا فعلاً أنا لكن أفضل؟ FASHN Edit قوي لكنه وحده لا يصنع wow دائم. QEL هو الفرق بين منتج عادي ومنتج عالمي.

    المسار الإلزامي — لا تخطّي QEL

    Analyze (Vision Platform) → segment + semantics + geometry
       ↓
OutfitGarmentRecolorPanel → Contextual Prompt v2 (Q0)
       ↓
FASHN Edit (Phase A)
       ↓
┌────────────────── Phase Q — Perceptual Validation ──────────────────┐
│  Identity Diff Gate (hybrid) · Skin Integrity (Perfect Corp)        │
│  Segment Drift Check (post-edit re-segment · IoU)                  │
│  Material Heuristic Lock (gloss · contrast · fold sharpness)       │
│  [Q2] Crop-first + polygon padding + composite (optional path)       │
│  Elite QEL Scorer (weighted sub-scores) · auto-retry max 2         │
└────────────────────────────────────────────────────────────────────┘
       ↓
MIRA Acceptance Gate (weighted threshold — ليس رقم أعمى واحد)
       ↓
UI Display (قبل/بعد) — أو رفض واضح بدون fake

    لماذا القماش ≠ لون فقط

    بُعد القماشإذا تجاهلته
    Texture · Fiber behaviorأسود حرير ≠ أسود كتان — يبدو plastic
    Light absorption · Reflectivitymatte → satin كارثة (Material Drift)
    Fold shadows · Material depthثنيات مسطّحة · fake
    Edge bleeding (جلد · شعر · إكسسوار)الثقة تنهار فوراً
    Identity (وجه · جسم · إضاءة)«هذه ليست أنا» — فشل المنتج

    Prompt Builder v2 — ثلاثي الوعي

    ليس semantic فقط — يجب أن يكون:

    البُعدمصادر MIRAمثال في البرومبت
    semantic-awarematerial · textureHints · colors«حافظي على خامة الساتان اللامعة…» (conditional إذا confidence ≥ 0.6)
    geometry-awareregionRole · fit · foldDensity · silhouette«حافظي على كثافة الثنيات في الكتف والصدر» (oversized · upper)
    material-awaregloss level · pattern · ontology«لا تحوّلي مطفي → لامع»

    ⚠️ لا تزعم خامة بثقة إذا providerConfidence < 0.6 — استخدم صياغة مشروطة.

    Identity Diff Gate — Hybrid (ليس SSIM وحده)

    إشارةالسبب
    Face embedding distanceهوية — أقوى من SSIM للوجه
    Landmark consistencyMediaPipe / pose — proportions
    Skin tone deltaundertone drift
    Skin Integrity Validator (Perfect Corp)undertone · texture class · tone zones — moat

    SSIM وحده ضعيف مع light shifts · exposure drift — استخدمه كإشارة مساعدة للخلفية فقط.

    Segment Drift After Edit — Q1 حاسم

    Original → Segment (mask M₀)
       → FASHN Edit
       → Re-segment Edited (mask M₁)
       → IoU(M₀, M₁) على garment region

إذا IoU < threshold → Reject
(اللون الجديد يغيّر contrast → الحدود القديمة لم تعد صالحة)

    Crop-first (Q2) — Polygon + padding

    لا bbox خام — padded polygon crop من segment map → edit على crop → composite مع feathering. bbox يلتقط background زائد؛ polygon أنظف للحواف.

    Elite QEL Scorer — weighted (ليس threshold أعمى)

    قبول مرجّح: QEL = w₁·Identity + w₂·Edge + w₃·Material + w₄·Region + w₅·Color · auto-retry max 2 · ثم رفض واضح للمستخدمة.

    Material Heuristic Lock — P1 (ليس P2)

    • gloss delta — luminance percentiles داخل garment mask
    • contrast map — local contrast قبل/بعد
    • fold sharpness — edge density في ثنيات القماش
    • عباءة matte → satin = reject (ثاني أكبر سبب fake بعد identity)

    خارطة Phase Q — Q0 → Q4

    ⛔ ممنوع

    • Phase A+ (multi-piece) قبل اكتمال Q1 على الأقل
    • Phase B (Try-On) قبل Q2 + Q3
    • عرض ناتج Edit في UI بدون MIRA Acceptance Gate
    • custom prompt حر يتجاوز QEL — Scorer يبقى السلطة
