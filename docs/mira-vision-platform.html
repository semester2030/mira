            API Contract — Endpoint واحد
            
        
            
          
            القاعدة: Flutter يعرف هذا فقط
            
          
            
            POST /ai/vision/outfit/analyze
          
            
        
            
        
            Request
            
        
            Content-Type: multipart/form-data

image: File (required)
occasionId: string (required)     // من ontology occasion
mode: "quick" | "smart" (required)
skinSnapshot: JSON (optional)     // مطلوب إذا mode=smart
locale: "ar" (default)
            
        
            Response 200
            
        
            {
  "fashionVision": { /* FashionVisionDocument v1 */ },
  "analysis": { /* OutfitAnalysis — من MIRA Engine */ },
  "meta": {
    "processingMs": 4200,
    "analysisGate": "proceed"
  }
}
            
        
            Response Errors (لا silent fallback)
            
        
            
          
            CodeالمعنىUX
            
          
            
            VISION_PROVIDER_FAILEDOpenAI أو FASHN فشلرسالة خطأ واضحة
            
            
            QUALITY_GATE_REJECTEDJSON غير صالحأعيدي التقاط الصورة
            
            
            CONFLICT_BLOCKEDتعارض حرج semantic/geometryأعيدي التقاط الصورة
            
            
            CONFIDENCE_TOO_LOWثقة < الحد الأدنىصورة أوضح مطلوبة
