# PHASE 8D — Analytics Report

Wired in `ResultsV2Analytics` (no intelligence payloads):

| Event | When |
|---|---|
| `result_metrics_viewed` | Metrics tab first view |
| `result_metric_opened` | Metric card → sheet |
| `result_metric_advisor_opened` | Ask Mira from metric |
| `result_metric_unavailable` | Unavailable metric path |
| `result_skin_map_viewed` | Map tab first view |
| `result_skin_map_info_opened` | Info sheet |
| `result_skin_map_concern_selected` | Concern chip |
| `result_skin_map_advisor_opened` | Ask Mira from map |
| `result_skin_map_unavailable` | Map unusable |

Payloads limited to public ids (metric_id / concern_id / analysis_id where applicable).
