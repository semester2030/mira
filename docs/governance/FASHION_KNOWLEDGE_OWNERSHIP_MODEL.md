# FK-1 — Ownership Model

## FKL owns
Fashion principles, conventions, dress-code knowledge, color relationships (fashion sense), accessory/footwear/bag/jewelry coordination knowledge, fabric/silhouette/proportion principles, occasion conventions, cultural fashion context (later), provenance, applicability, exceptions, conflict relationships, knowledge confidence, lifecycle, trend windows.

## FKL does NOT own
Garment detection/canonicalization, OI scoring ownership, wardrobe persistence, Style Decisions / goals ledger, recommendation commerce ranking, shopping inventory, free-form conversation, provider adapters.

## Boundary table
| Concern | Owner |
|---|---|
| What is worn | Garment Intelligence |
| How pieces relate (evidence) | Outfit Intelligence |
| What knowledge applies | **Fashion Knowledge Layer** |
| User prefs / goals | Styling Intelligence (consume) |
| Narration | AI Beauty Advisor |
