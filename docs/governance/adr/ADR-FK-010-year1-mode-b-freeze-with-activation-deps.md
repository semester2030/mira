# ADR-FK-010 — Year-1 Mode-B platform freeze with activation dependencies

**Status:** Accepted · Frozen in Fashion Knowledge Platform v1.0.0 (`MIRA-FK-FREEZE-1.0.0`)  
**Date:** 2026-08-10

## Context
Year-1 Fashion Knowledge must be governed without implying curated completeness or live Nest Mode B activation.

## Decision
Freeze certifies architecture under FK-13 B; Nest provider, consent, curated population remain activation dependencies.

## Consequences
Semantic change requires CR per FK-14 change/breaking policies. Activation dependencies remain explicit and separate from technical debt.
