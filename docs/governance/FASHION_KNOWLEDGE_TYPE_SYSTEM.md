# FK-1 — Knowledge Type System

Authority order (high → low) for automatic preference — **not** absolute override of user preference:

1. `DRESS_CODE_RULE` / `CULTURAL_CONVENTION` (when applicable + reviewed)
2. `ESTABLISHED_PRINCIPLE`
3. `CONVENTION`
4. `PROFESSIONAL_OPINION`
5. `TREND` (time-bounded)
6. `LLM_GENERAL_KNOWLEDGE` (temporary, always qualified)
7. `USER_PREFERENCE` — **not domain truth**; input to conflict policy (owned by SI context)

Public claim strength must decrease with authority and increase with subjectivity.
