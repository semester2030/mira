# FK-5A — Source Requirements

Each of 17 candidates has required evidence class(es):
- Color theory facts → COLOR_MATH_REFERENCE + COLOR_THEORY_REFERENCE
- Color styling conventions → FASHION_STYLING_REFERENCE (+ theory where relevant)
- Occasion formality → OCCASION_REFERENCE + FORMALITY_REFERENCE
- Dress code → DRESS_CODE_REFERENCE + FORMALITY_REFERENCE
- Day/evening → DAY_EVENING_REFERENCE + OCCASION_REFERENCE
- Color×occasion intersection → OCCASION + FORMALITY + FASHION_STYLING

Dress-code sources must not substantiate unrelated color-theory claims.
