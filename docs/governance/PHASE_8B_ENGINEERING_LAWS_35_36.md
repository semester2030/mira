# PHASE 8B — Engineering Laws #35 & #36

## Law #35
Every result presented must have one clear meaning, one evidence source, one confidence state, one recommended action, one presentation owner.  
Code: `laws/engineering_laws_35_36.dart` + validator `_law35`.

## Law #36
Public Results Experience must never expose provider/canonical/raw/trace/internal version/MCE/mapping/engine metadata.  
Code: `PublicLanguagePolicy` + validator `_law36` / language checks.

These laws apply to the Results Presentation Layer only and do not change Laws #1–#34 ownership.
