# Provider License Policy

**Version:** `provider-license-policy-v1`  
**Laws:** #19 · #21 · #22

## States (never inferred)

| Status | Meaning |
|--------|---------|
| purchased | Business purchase recorded; not yet verified |
| verified | Operator attached evidence; console/units confirmed |
| expired | Past expiry |
| unknown | Default — **do not activate** |
| pending | Verification in progress |
| rejected | Verification failed |

## Rules

1. Buying a provider is a **business** action — not a development project (Law #19).  
2. License must be **verified before activation** (Law #21).  
3. Skin `PERFECT_API_KEY` presence ≠ Makeup VTO license verified.  
4. Mark verification via operator API/method + evidence ref — never by assuming API docs alone.
