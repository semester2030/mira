# PHASE 9H — Advice Ownership Policy

**Rule:** one owner per advice concept. Face Experience must not absorb other domains.

| Concept | Owner |
|---|---|
| Face structural explanation | Face Experience / 9E projection |
| Face styling recommendation (hairstyle, makeup_contour, eyewear, accessories, educational) | Face Intelligence → 9H projection |
| Skin treatment | Skin |
| Fashion/style beyond Face-owned wire | Fashion / Fashion Knowledge |
| Conversation narration | Advisor |
| Generic beauty tips | GENERIC_STATIC (legacy; not personalized on 9H) |

Runtime: `FaceGuidanceOwnershipPolicy`.
