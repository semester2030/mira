# Server Authority Matrix

| Concern | Authority |
|---|---|
| Face statement text | Stored `FaceIntelligenceReportDto` fields only |
| Recommendation body/reason | Stored `FaceRecommendation` |
| Shape / findings / metrics | Stored report |
| Region policy text | Server constant illustrative string |
| Provenance CANONICAL_FACE | Assigned only on server-derived units |
| Ownership | `userId` + skinAnalysis id |
