# PHASE 8A — Interaction Architecture

| Interaction | User need |
|-------------|-----------|
| Expand metric | Understand meaning without clutter |
| Swipe/tap priority cards | Focus top 3 |
| Tap-to-explain score | Direction + thresholds in plain language |
| Tap evidence | Supporting evidence sheet |
| Map concern select | Illustrative regions + honesty badge |
| AM/PM routine toggle | Reduce routine length |
| Today / Weekly / Progress tabs | Separate time horizons |
| Mark routine done | Habit loop (local) |
| Ask Advisor about priority | Envelope-bound discussion |
| Compare previous | Only if comparable |
| Retake | Recovery |
| Save product / explain match | Commerce clarity |
| Hide general advice | Reduce noise |

No decorative-only interactions.
