# PHASE 8A — Target Experience Architecture

## Option evaluation
| Option | Pros | Cons | Fit |
|--------|------|------|-----|
| A One summary + disclosure | Fast comprehension | Hard to scale modules | Partial |
| B Tabbed report | Clear IA | Weak first answer if tabs bury summary | Partial |
| C Multi-screen journey | Guided | High drop-off; Arabic RTL back stack | Weak |
| **D Hybrid summary + tabs + sheets** | First answers + depth + Advisor/progress/commerce slots | Needs projection layer | **Selected** |

## Selection criteria → D
Comprehension, length control, interaction depth, a11y, RTL, future modules, Advisor, progress, commerce, analytics — best balanced by hybrid.

## First user-visible surface (hard cap)
1. Primary result summary (vitality + skin type + one sentence)  
2. ≤3 priorities  
3. One immediate action (today)  
4. One routine entry  
5. One progress entry  
6. One Advisor entry  
Plus: compact trust/confidence chip (not full layer)

## Secondary
Tabs/sheets: Metrics · Map · Plan · Progress · Products · Trust details

## Frozen boundary
Presentation only — no intelligence recalculation.
