# PHASE 8A — Result Design System Extension

## Audit (current)
- Dense PremiumCard stack; gold/pink Mira tokens  
- BeautyScoreRing for vitality  
- Long SingleChildScrollView; weak sticky actions  
- RTL generally supported via Arabic copy; hierarchy noisy  

## Extension (not full rebrand)
| Token | Rule |
|-------|------|
| Hierarchy | 1 hero score · priority list · action bar |
| Color | Condition health ≠ confidence (blue-gray) ≠ projection (dashed/muted) ≠ burden metrics (amber scale) |
| Cards | Prefer section surfaces; cards only for interactive units |
| Sticky | Today action + Advisor on summary |
| Type | Existing AppTypography; reduce titleMedium spam |
| Motion | StaggeredEntrance keep; add expand/collapse only |
| A11y | Dynamic Type, contrast on gold/light backgrounds, large tap targets |
| RTL | Mirror tabs/chevrons; no leading Latin jargon |
