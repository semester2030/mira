# ميرا — إصلاح العدسة ونطاق الدرجة ووضوح الخريطة

هذه حزمة تغييرات فعلية مبنية على `MIRA_FACE_EXPLORER_REFACTOR_PARITY_REVIEW.zip`، وليست نسخة تطبيق مثبتة أو شهادة مطابقة بصرية. احتُفظ بتقسيم الملفات وترتيب الواجهة الواردين في آخر مراجعة.

## ما تغيّر

| البند | الإصلاح |
|---|---|
| حجم العدسة | قراءة المساحة الفعلية من LayoutBuilder وإلغاء افتراض عرض 400 |
| موضع التكبير | نقل بكسل المصدر المختار إلى مركز العدسة؛ ×2 و×3 نسبةً إلى صورة الوجه الرئيسية |
| تطابق الصورة والقناع | عرضهما داخل المستطيل نفسه؛ كائن واحد للقناع وراية فكّه يُمرر إلى الشاشة والعدسة |
| الرجوع للقناع الخام | `presentationDecoded` تظل false عند فشل التحويل أو إرجاع بيانات فارغة |
| نطاق الدرجة | إظهار «درجة الجبهة» عند ارتباط الدرجة بالجبهة؛ عدم استبدال الدرجة الغائبة بدرجة عامة أو صفر |
| مؤشر موضع الفحص | تمركز الدائرة على الإحداثية الفعلية، دون انزياح ناشئ عن حجم دائرة Align |
| المقارنة | إخفاء الخريطة مع إبقاء الصورة والخلفية وحجم العرض ثابتة |
| انتقال المحاولة | مسح الصورة السابقة قبل بدء قراءة الجديدة وإعادة ضبط موضع العدسة |

## وضوح الخطوط والألوان

المصدر الهندسي ما زال قناع التحليل نفسه. لم تُرسم تجاعيد أو نقاط إضافية، ولم تُغيّر الدرجات أو عتبات كشف الإشارة أو توسع مناطق القناع.

- التجاعيد: عتامة عرض لا تقل عن 0.96، وحد أدنى 210/255 لألفا البكسلات التي اجتازت التحويل أصلًا.
- المسام والحبوب والتصبغات: عتامة لا تقل عن 0.94، وحد أدنى 200/255 للبكسلات الموجودة أصلًا.
- الدهون: عتامة لا تقل عن 0.84، مع حفظ تدرج ألفا الحالي دون تحويل المساحة إلى تعبئة موحدة.
- لون العلامة مأخوذ من ألوان ميرا المعتمدة؛ إلغاء خفض ألفا اللون الإضافي في هذه المؤشرات. بقية المؤشرات تحافظ على إعداداتها الحالية.
- في الرقعة الثانية: استخدام `FilterQuality.medium` للأقنعة المحوّلة فقط. هذا يقلل فقد تفاصيل الخطوط عند تصغير عرضها، بدل أخذ أقرب بكسل فقط. القناع الخام يحتفظ بمساره الحالي حتى يُفك معناه أولًا. المرجع: [وثائق Flutter لجودة أخذ عينات الصور](https://api.flutter.dev/flutter/dart-ui/FilterQuality.html).

قيم التباين أعلاه إعدادات عرض مرشحة للاعتماد على الجهاز؛ ليست معايرة مثبتة على أقنعة محاولة المستخدم الحالية. لا تضيف دقة علمية إلى التحليل. لا يمكن استعادة مسار غير موجود في بيانات المزود برفع وضوحه.

## طريقة الدمج

1. طبّق `01_four_fixes.patch` على مشروع ميرا الحالي، ثم `02_renderer_sampling.patch` بعد فحص التوافق. الرقعتان بمسارات نسبية إلى جذر المشروع.
2. ملفات `source/` تشمل الملفات المعدلة والجديدة للمراجعة. لا تنسخها فوق نسخة أحدث دون مقارنة.
3. تعديل `perfect_mask_overlay.dart` مقدّم **كرقعة محدودة فقط**؛ أحدث نسخة كاملة متاحة هنا من حزمة `MIRA_SKIN_MAP_VISUAL_TRUTH_REVIEW.zip`. لذلك لم نضع نسخة قديمة كاملة لاستبدال الملف الحالي. إذا اختلف السياق، انقل تعديل جودة العينات إلى المواضع المناظرة في النسخة الحالية، مع حفظ بقية الكود.
4. شغّل تنسيق Dart والتحليل والاختبارات داخل المشروع الكامل، ثم ابنِ نسخة الجهاز. لا تعتمد سجلات البناء السابقة لهذه التغييرات.

من جذر مشروع ميرا، باستخدام المسار الفعلي إلى الحزمة:

```sh
git apply --check /path/to/bundle/01_four_fixes.patch /path/to/bundle/02_renderer_sampling.patch
git apply /path/to/bundle/01_four_fixes.patch /path/to/bundle/02_renderer_sampling.patch
flutter test test/features/results_experience/face_explorer_four_fixes_test.dart
```

إذا تعارضت الرقعة مع تغييرات أحدث، ادمج الإصلاحات في تلك النسخة دون إرجاع الملف إلى نسخة المراجعة القديمة. حافظ على التصوير اليدوي وواجهات التحليل ودرجات المزود.

## ما تم التحقق منه هنا

- نجح فحص البنية النحوية لملفات Dart بأداة تحليل نحوي؛ هذا لا يعادل فحص الأنواع أو `flutter analyze`.
- نجح `git apply --check` على النسخ المصدرية المرفقة.
- طابقت بايتات الملفات الناتجة بعد تطبيق الرقعتين الملفات المعدلة.
- أُرفقت 13 حالة اختبار Dart/Flutter لهندسة العدسة، حجمها الفعلي، القناع الخام/المحوّل، الحفاظ على البكسلات غير النشطة، انتقال الصورة، ونطاق الدرجة.
- **لم تُشغّل اختبارات Flutter أو بناء iOS هنا** لعدم توفر SDK والمشروع الكامل. الاختبارات الجديدة ليست سجل نجاح.

التفاصيل في `VALIDATION.json`، ومصادر الملفات وبصماتها في `FILE_MANIFEST.json`.

## قبول النتيجة على الجهاز

اختبر محاولة حقيقية واحدة مع صورتها وأقنعتها: التجاعيد والدهون والمسام أولًا، ثم بقية المؤشرات المتاحة. المطلوب لقطة بالحجم الطبيعي، وعدسة ×2 و×3، ولمس الجبهة والخد، وتحريك المنزلقين، واختيار منطقة ذات درجة وأخرى بلا درجة، والمقارنة بالأصل.

يجب أن تكون العلامة نفسها داخل العدسة وفي الصورة، والنقطة المختارة في مركز العدسة، والخطوط مقروءة دون تكبير. قارن الواجهة بالتصور المعتمد عند عرض متساوٍ. لا يُعلن تحقق المطابقة 100% أو وضوح جميع الأقنعة قبل هذه المقارنة. عند بقاء قناع ضعيف يُفحص الخام والمحوّل والرسم من المحاولة نفسها؛ لا تُضاف علامات لإخفاء نقص البيانات.
