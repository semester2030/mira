# FK-1 — Subjectivity Model

| Level | Meaning | Public tone |
|---|---|---|
| LOW_SUBJECTIVITY | Established visual principle | Factual observation OK |
| MEDIUM_SUBJECTIVITY | Convention | Conditional |
| HIGH_SUBJECTIVITY | Taste-driven opinion | “إذا كنتِ تفضلين…” |
| TREND_DEPENDENT | Time-sensitive | Label as trend + validity |
| USER_DEPENDENT | Preference-driven | Offer alternatives |

Forbidden: “هذا لا يناسبك” as absolute taste fact.
