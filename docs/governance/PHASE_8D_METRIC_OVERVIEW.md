# PHASE 8D — Metric Overview

Each card shows:
- public name (`titleAr`)
- semantic status (`MetricPresentationPolicy.publicStatusAr`)
- one-line meaning (`summaryAr` / explanation)
- confidence chip (state, not raw %)
- visual role color distinct for severity vs wellness
- optional numeric only when `numericVisible`
- Semantics label for VoiceOver
- tap → detail sheet

Hidden when `VisibilityPolicy` says not public. No filler metrics.
