# مصفوفة حدود ما بعد الالتقاط — ضروري vs إرشادي

المصادر: `CaptureQualityThresholds` (cq-thresholds-v2.1)، `FaceGateRules`، `QualityConfidenceMapper`.

**سياسة المنتج المصحَّحة:** تصوير يدوي بسيط → تحليل.  
لا تُرفض الصورة لأن الحزمة القديمة «كما هي» حجبتها. الرفض فقط عندما يكون التحليل غير ممكن بصدق أو شبه مؤكد الفشل عند المزود.

---

## A) FaceGateRules (على الملف بعد الضغطة)

| شرط | قيمة حالية | مبرر تقني | تصنيف للمسار المبسّط | رسالة عربية موجودة |
|-----|------------|-----------|----------------------|-------------------|
| `faceCount == 0` | — | لا مدخل للمزود | **رفض ضروري** | لم نتعرف على وجه… |
| `faceCount > 1` | — | تحليل وجه واحد فقط | **رفض ضروري** | وجدنا أكثر من وجه… |
| `faceAreaRatio < min` | **0.05** | وجه صغير جداً غالباً يفشل YouCam | **رفض ضروري** | الوجه بعيد جداً… |
| `faceAreaRatio > max` | **0.92** | وجه مقصوص/قريب جداً | **رفض ضروري** | الوجه قريب جداً أو مقصوص… |
| `|yaw| > max` | **35°** | وضعية جانبية | **إرشادي** في المسار المبسّط (لا ترفض محلياً؛ إرشاد قبل/بعد + اعتماد رفض المزود إن لزم) | وجّهي وجهك… |
| `|pitch| > max` | **30°** | إمالة رأس عمودية | **إرشادي** | عدّلي زاوية الرأس عمودياً… |
| `|roll| > max` | **28°** | ميلان | **إرشادي** | عدّلي زاوية الرأس… |
| `|centerOffsetX| >` | **0.13** | خارج المنتصف أفقياً | **إرشادي** | الوجه ليس في المنتصف… |
| `|centerOffsetY| >` | **0.11** | خارج المنتصف عمودياً | **إرشادي** | عدّلي موضع الوجه عمودياً… |

> الدراسة السابقة اقترحت تشغيل كل `FaceGateRules` كرفض. ذلك يعيد تكرار الرفض (وضعية/مركز) بعد أن ضغطت المستخدِمة. التصحيح: **عدد الوجوه + مساحة الوجه القصوى/الدنيا فقط** كرفض محلي إلزامي من FaceGate.

## B) ImageQualityEvaluator → QualityConfidenceMapper

| مقياس | حد حجب حالي | حد تحذير / دور | تصنيف للمسار المبسّط | مبرر |
|-------|-------------|----------------|----------------------|------|
| decode فاشل | blocked | — | **رفض ضروري** | لا ملف صالح |
| `blur` Laplacian | **< 28** يحجب | **< 55** يخصم ثقة فقط | **رفض ضروري** إن < 28؛ < 55 إرشادي | ضبابية تُفسد التحليل |
| `brightness` | خارج **[0.18, 0.92]** | المثالي **[0.32, 0.78]** يخصم ثقة | **رفض ضروري** خارج [0.18, 0.92] فقط؛ المثالي إرشادي | ظلام/سطوع متطرف |
| `overexposure` ratio | **> 0.18** يحجب اليوم | — | **إرشادي** للمسار المبسّط (تجنّب رفض متكرر؛ المزود قد يرفض لاحقاً برسالة واضحة) | |
| `underexposure` ratio | **> 0.22** يحجب اليوم | — | **إرشادي** | |
| `shadowImbalance` | **> 0.35** يحجب | warn **0.22** | **إرشادي** | |
| `resolutionShortEdge` | **< 480 px** يحجب | — | **رفض ضروري** | دقة غير كافية |
| contrast / dynamicRange | لا يحجبان | informational | **إرشادي دائماً** | Option A في العتبات |
| yaw/pitch/roll داخل IQ mapper | نفس درجات FaceGate | warnCombinedAngle **15°** | **إرشادي** (لا رفض مزدوج) | |
| faceCount / coverage داخل IQ | مكررة مع FaceGate | — | تُستمد من FaceGate الضروري فقط | تجنّب رفض مزدوج |

## C) ماذا يفعل التنفيذ لاحقاً (دراسة فقط)

1. بعد `takePicture`: فحص الحد الأدنى أعلاه فقط → إن رُفض: رسالة واحدة واضحة + معاينة فورية.
2. لا انتظار CameraKit READY.
3. إضاءة/مسافة/وضعية أثناء المعاينة = نص إرشاد من CameraKit أو mesh — **لا شرط زر**.
4. إن قبل الفحص المحلي وفشل Perfect/YouCam بسبب الوجه: اعرض رسالة المزود المترجمة — لا خرائط وهمية.

## D) ما لن يُعاد تشغيله «كما هو»

`QualityConfidenceMapper.map` الحالي يحجب على over/under exposure وshadow وpose معاً → **غير مناسب** كبوابة افتراضية للمسار اليدوي المبسّط دون تصفية التصنيف أعلاه.
