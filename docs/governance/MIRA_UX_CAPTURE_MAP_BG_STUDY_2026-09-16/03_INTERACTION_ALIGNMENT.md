# 03 — التفاعل والمحاذاة

## تدفق التفاعل المستهدف (فوق الموجود)

```
كاروسيل مؤشر
   → اختيار
   → crossfade قناع (إن وُجد) + تحديث درجة + شرح عربي موجز
   → (اختياري) مكبّر على مركز إشارة القناع الحقيقية
   → ضغط مطوّل: إخفاء قناع/خلفية عرض وإظهار الأصل (_sourceBytes)
   → رفع الإصبع: العودة للعرض المركّب
```

## ما يُحافظ عليه حرفياً

| قدرة | ملف | ملاحظة |
|------|-----|--------|
| `SharedImageMaskFit.containRect/coverRect` | `shared_image_mask_fit.dart` | صورة + قناع نفس المستطيل |
| `PerfectMaskOverlay` | `perfect_mask_overlay.dart` | لا BoxFit مستقل لكل طبقة |
| ضغط مطوّل أصل | `results_skin_map_panel.dart` `_holdingOriginal` | يبدّل مصدر البايتات للعرض |
| مكبّر | `PerfectMaskMagnifierFocus` | من بكسلات القناع فقط؛ يُلغى لـ scoreOnly |
| انتقالات | `SkinFaceMapVisualTokens.selectionTransition` إلخ | 180–220ms |

## قيود عند تغيير الخلفية (بند 4)

1. الماتّة الملوّنة والوجه يجب أن يبقيا على **نفس أبعاد المصدر** (`width`/`height` من قناة Apple).
2. القناع Perfect يُرسم فوق الوجه بنفس `destRect` بغض النظر عن لون الخلفية.
3. أثناء `_holdingOriginal`: عرض `_sourceBytes` كاملة (بخلفية المشهد الأصلية) — ليس الماتّة.
4. أي انعكاس/دوران/قص للعرض يُطبَّق عبر التحويلة المشتركة الحالية — لا فرع جديد للخلفية الوردية.

## ما لا يُعاد بناؤه

- لا مسار محاذاة ثانٍ.
- لا ClipOval كعزل وجه.
- لا مكبّر يعتمد على landmarks بدل القناع.
