# FK-1 — Color Knowledge Architecture

Separate three layers:
1. **Deterministic color math** (hue distance, complementary angles) — computable; cite algorithm version
2. **Fashion convention** (neutral balancing for occasion) — curated rules
3. **Subjective styling** (prefer softer for user goal) — HIGH_SUBJECTIVITY

Do not mix Flutter `FashionColorHarmonyEngine` scores into Nest as “Mira truth” without promotion pipeline.

Nest `isClashPair` remains engineering heuristic until replaced/superseded by curated rules.
