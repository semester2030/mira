# تحسين جوال بوابة الشركاء (منتجاتي / المحرر)

## ماذا تغيّر
- شريط علوي مضغوط + زر قائمة يفتح درج تنقل من اليمين ويُغلق عند الاختيار.
- بعد اكتمال اختيار القسم/التصنيف تُطوى الدوائر إلى سطر: `أناقتك ‹ الملابس ‹ سهرة` مع «تغيير» (يحفظ الحقول).
- تعديل منتج موجود يبدأ مطويًا؛ الاسم والسعر يظهران مبكرًا؛ الوسائط في تبويب «الوسائط» فقط على الجوال.
- زر الحفظ مثبت أسفل الشاشة مع `safe-area`؛ أهداف لمس ≈44px؛ بدون سحب أفقي للصفحة.
- سطح المكتب 1440 يبقى كما هو (زر القائمة مخفي، الشريط 220px، منتقي التصنيف ظاهر).

## إثبات محاكاة (Playwright / Chrome headless)
انظر `RESULTS.json` والقطات `01`–`06`.
- لوحة المفاتيح: **محاكاة فقط** (لم يُختبر على جهاز فعلي في هذه الجولة).
