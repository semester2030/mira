# منتجاتى فارغة + تخطيط البوابة

## السبب الفعلي
بعد دخول حساب `developer`، لوحة التحكم ترسم نموذج الخدمات (`renderForm('clinic', …, 'serviceForm')`) أثناء البقاء على مسار `#/products`. هذا كان يستدعي `MiraE2BServiceShell.enableServiceMode` → `clearProductModeArtifacts` فيُضبط `#catalogSection.hidden = true` ويُضاف `e2c-inactive-editor`. واجهة الشِل تظل تعرض عنوان «منتجاتي» وزر الإضافة، بينما قائمة المنتجات في DOM بعرض/ارتفاع 0 (display:none على القسم). عدّاد «عناصر الكتالوج» كان صحيحًا لأنه يُحسب من `productCount + serviceCount` قبل إخفاء القسم.

## الإصلاح
- عدم تفعيل وضع الخدمة عند طلاء `serviceForm` الخامل أثناء عرض المنتجات.
- إخفاء كتالوج المنتجات فقط عندما `data-portal-view=services`.
- إعادة إظهار `#catalogSection` وتفعيل وضع المنتج عند التنقل إلى منتجاتى.
- حالات قائمة واضحة: تحميل / فارغ / خطأ+إعادة / مسح فلاتر.
- تخطيط ممتد بعرض النافذة: شريط ~220px، هيدر 60–64px، هامش ~22px.
- «إضافة منتج» يفتح نموذجًا فارغًا مستقلًا.
