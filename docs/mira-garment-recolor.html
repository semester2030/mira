    الخصوصية — بدون استثناء

    • المعالجة على سيرفر ميرا فقط — المفتاح السري لا يصل للتطبيق
    • الصورة في الذاكرة أثناء الطلب — لا تُحفظ في PostgreSQL

    • النتيجة تُعرض محلياً في الجلسة — لا رفع تلقائي

    عقد API

    POST /api/v1/ai/vision/outfit/recolor
Authorization: Bearer <Firebase ID Token>
Content-Type: multipart/form-data

Fields:
  image            (file, required)
  targetColorAr    (string, required)  — مثال: "أسود"
  targetColorHex   (string, optional)  — مثال: "#1A1A1A"
  garmentLabelAr   (string, optional)  — مثال: "فستان"
  customPromptAr   (string, optional)  — برومبت معدّل من التطبيق
  visionContext    (string, optional)  — JSON Phase Q0/Q2 (bbox · polygon · material)
  locale           (string, default ar)

    تكامل Flutter — فصل «جرّبي»

    • OutfitGarmentRecolorPanel — شرائح ألوان + حالة تحميل + مقارنة قبل/بعد
    • VisionApiDataSource.recolorGarment() — timeout 120s
    • رسائل ميرا أثناء الانتظار: «ميرا تعيد تلوين إطلالتك…»

    إصلاح خريطة القطع — فصل «إطلالتك»

    الطبقة الملوّنة المملوءة تسبب انقساماً بصرياً (أزرق + كحلي). الحل: outline-only — حدود وتوهج بدون fill.
